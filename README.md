# متجر الحي | La Boutique du Quartier

واجهة متجر إلكتروني عربية/فرنسية/إنجليزية، تعرض المنتجات من Supabase وتسمح بإرسال الطلب عبر WhatsApp. تتضمن لوحة إدارة للمدير وملفات PWA للتثبيت على الهواتف.

## الملفات
- `index.html`: واجهة المتجر والمنطق البرمجي.
- `manifest.webmanifest`: بيانات تثبيت التطبيق.
- `sw.js`: Service Worker لتخزين غلاف التطبيق مؤقتًا ودعم فتحه عند انقطاع الاتصال (المنتجات وطلبات واتساب تحتاج اتصالًا).
- `icons/`: أيقونات التطبيق.
- `assets/css/style.css`: ملف CSS إضافي موجود في المشروع الأصلي؛ التنسيقات الأساسية للواجهة حاليًا داخل `index.html`.

## إعداد Supabase
يعتمد الكود على مشروع Supabase المحدد في أعلى `index.html` وعلى المفتاح العام Publishable/anon. لا تضع أبدًا `service_role` أو أي مفتاح سري داخل ملفات الواجهة.

يتوقع الكود وجود الجداول/الأعمدة التالية على مخطط `public`:
- `categories`: `id`, `name_ar`, `name_fr`, `name_en`, `created_at`.
- `products`: `id`, `name_ar`, `name_fr`, `name_en`, `description_ar`, `description_fr`, `description_en`, `category_id`, `price_individual`, `price_retail`, `price_wholesale`, `wholesale_min_quantity`, `stock`, `image_url`, `active`, `created_at`.
- دالة RPC باسم `is_store_admin()` للتحقق من صلاحية مدير المتجر.
- Storage bucket باسم `product-images` لصور المنتجات، مع سياسات رفع/قراءة مناسبة.

**مهم:** تم توحيد شرط تفعيل المنتج في الواجهة على اسم العمود `active` بدل `is_active` وفق بنية قاعدة البيانات التي ظهرت أثناء إصلاح المشروع. راجع أن سياسات RLS تسمح بقراءة المنتجات النشطة والأقسام، وتقيّد الإضافة والتعديل والحذف بمدير المتجر.

## التشغيل والنشر
1. ارفع محتويات هذا المجلد كاملة إلى جذر مستودع GitHub (لا ترفع ملف ZIP بدل الملفات).
2. فعّل GitHub Pages من إعدادات المستودع: Settings → Pages → Deploy from a branch، ثم اختر الفرع ومجلد `/ (root)`.
3. افتح رابط الموقع عبر HTTPS. سيعمل المتجر في المتصفح، ويمكن تثبيته من المتصفح على Android أو إضافته للشاشة الرئيسية من Safari على iPhone.
4. بعد كل تعديل، حدّث `CACHE_NAME` في `sw.js` (مثل `matjar-alhay-v2`) حتى تصل النسخة الجديدة إلى الأجهزة التي خزّنت النسخة السابقة.

## حدود النسخة
- الدفع غير مدمج؛ الطلب يُرسل إلى رقم WhatsApp المحدد في `index.html`.
- PWA قابلة للتثبيت، لكنها ليست حزمة APK أو تطبيقًا منشورًا في Google Play/App Store.
- لم يتم إجراء اتصال حي بقاعدة Supabase أو اختبار تسجيل الدخول/الطلبات من هذا الملف وحده؛ يلزم اختبارها بعد النشر باستخدام إعدادات مشروعك الفعلية.
